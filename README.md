# Travel Agency Website

A full-stack web application built to streamline travel agency operations, including user account management, train schedule browsing, and booking management.

## Features
- **User Authentication:** Sign up and login functionality for users.
- **Booking Management:** Interface to view train details and confirm bookings.
- **Database Integration:** SQL scripts provided for setting up and managing backend data.

## Tech Stack
- **Backend:** Python (Flask)
- **Frontend:** HTML, CSS
- **Database:** MySQL

## Repository Structure
- `app.py`: Main Flask application file containing route logic.
- `templates/`: HTML templates for website pages.
- `*.sql`: Database setup and structure files.
